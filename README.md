# Responsive Contact Form ✉️

A clean, modern, and responsive contact form built with HTML, CSS, and vanilla JavaScript. This project features client-side form validation and is fully optimized for a seamless experience across desktop, tablet, and mobile devices.

## 🚀 Live Demo
[View Live Project](https://sedrah03.github.io/contact-form/) 

## ✨ Features
* **Fully Responsive:** Adapts beautifully to screens of all sizes (mobile, tablet, desktop).
* **Client-Side Validation:** Ensures users fill out required fields correctly before submission.
* **Modern UI/UX:** Clean styling with smooth hover transitions, focus states, and a subtle drop shadow.
* **Accessible:** Uses semantic HTML, `aria-live` regions, and proper `<label>` associations for screen readers.
* **Visual Feedback:** Built-in error and success message handling for user interactions.

## 🛠️ Technologies Used
* **HTML5:** Semantic structure and built-in form validation.
* **CSS3:** Custom styling, Flexbox for centering, media queries for responsiveness.
* **JavaScript:** Logic for custom validation and form submission handling.
